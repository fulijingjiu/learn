# Python：基础与开发知识

## 语言直觉

- 动态类型 + **类型提示**（`def f(x: int) -> str`）方便人和 IDE，不替代运行时校验
- 万物对象；缩进即块
- **可变**默认参数陷阱：别写 `def f(a=[])`，用 `None` 再创建
- 推导式简洁，别嵌套三层难读

## 必会清单

- 容器：`list`/`dict`/`set`/`tuple`；字典键要可哈希
- 迭代：`for`、生成器、`yield`（省内存）
- 异常：`try/except/finally`；窄捕获，少裸 `except:`
- 文件与路径：`pathlib.Path`；`with` 开关文件
- 模块：`import`；包是含 `__init__.py` 的目录（命名空间包例外）
- 常用库：`json`、`datetime`（注意时区）、`logging`、`subprocess`

## 环境与依赖

- **venv**（或 uv/poetry）：一项目一环境，不污染系统 Python
- `requirements.txt` 或 `pyproject.toml` 锁版本；生产与本地一致
- 多版本可用 pyenv；容器里固定基础镜像 tag

## 开发习惯

- 格式化：`ruff`/`black`；静态检查：`ruff`/`mypy`（按需）
- 日志用 `logging`，别乱 `print`（脚本调试可临时 print）
- 密钥：环境变量 / `.env`（不进 git）
- 测试：`pytest`；对纯函数先单测

## 面试口述

1. **列表和元组？** 列表可变；元组不可变，可作字典键。
2. **GIL？** CPython 同一时刻一个线程执行字节码；CPU 密集用多进程/原生扩展；IO 密集线程/asyncio 仍有用。
3. **`==` vs `is`？** `==` 比值；`is` 比身份（单例/`None` 用 `is`）。
