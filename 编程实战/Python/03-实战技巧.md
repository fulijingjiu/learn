# Python：实战技巧

## 项目结构（FastAPI 示例）

```
app/
  main.py          # 创建 app、挂路由
  api/             # 路由
  schemas/         # Pydantic 模型
  services/        # 业务
  repositories/    # 数据访问
  core/config.py   # 配置
```

避免「一个 `utils.py` 一万行」。

## 配置

- `pydantic-settings` 读环境变量；分 `dev/staging/prod`
- 数据库 URL、密钥不进仓库；十二要素

## 数据访问

- SQL 多、要可控：SQLAlchemy / 手写 SQL + 预编译参数
- 简单 CRUD：也可 SQLModel（贴合 FastAPI）
- 事务：一个请求一个 session/连接；写操作显式 commit；异常 rollback
- 和 DB 八股对照：索引、慢 SQL、隔离级别 → `/workspace/面试八股/`

## 异步注意

- `async def` 里不要直接跑重 CPU 或阻塞驱动
- 调用同步库：`asyncio.to_thread` 或换异步驱动
- 超时、取消、重试要有上限

## API 实战

- 版本前缀 `/api/v1`；错误结构统一
- 分页：`limit`+`cursor` 或 page；强制 max limit
- 后台任务：Celery / ARQ / 云队列；别在请求里干重活不设超时

## 脚本与运维

- 入口用 `if __name__ == "__main__"`；CLI 用 `typer`/`argparse`
- 容器：非 root、健康检查、优雅退出（处理 SIGTERM）
