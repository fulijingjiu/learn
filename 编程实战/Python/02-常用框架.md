# Python：常用框架（怎么选 + 核心 + 口述）

## 怎么选

| 场景 | 选型 |
|---|---|
| 新 API、要自动 OpenAPI、类型提示友好 | **FastAPI**（推荐默认） |
| 全能后台、Admin、ORM 全家桶、内容站 | **Django** |
| 极简、微原型、嵌入现有 WSGI | **Flask** |
| 表格清洗、分析、报表 | **pandas**（+ SQL/文件）；不是 Web 框架 |

「只要一个 REST 服务」→ FastAPI。  
「要管理后台和用户权限开箱」→ Django。  
「老项目/插件式」→ Flask。

## FastAPI 核心

- 基于 **Starlette** + **Pydantic**；路径函数 + 类型注解 → 校验与文档
- 依赖注入：`Depends`；适合鉴权、DB session
- 可 async；阻塞 IO 别堵事件循环（用线程池或换同步驱动策略）
- 部署：`uvicorn`/`gunicorn`+workers

## Django 核心

- MTV：Model / Template / View；自带 ORM、Admin、auth
- 迁移：`makemigrations` / `migrate`
- 重而全；API 可用 DRF（Django REST Framework）

## Flask 核心

- 微核 + 扩展；路由装饰器；灵活但要自己拼结构
- 适合小工具、内部接口

## pandas（一句）

`read_csv`/`read_sql` → 筛选 `df[cond]` → `groupby` 聚合 → `to_csv`；大表注意内存，能下推 SQL 就下推。
