# 02 · 常用框架与工具（概念对比）

> 框架迭代快，以官方文档为准。这里只记**选型直觉**，方便口述。

## 一张表

| 名称 | 定位 | 何时优先考虑 | 备注 |
|---|---|---|---|
| **LangChain** | LLM 应用组件库（模型、提示、检索、工具集成） | 快速拼装链 / RAG / 工具 | 生态大；复杂状态控制常配 LangGraph |
| **LangGraph** | 有状态、可控的 Agent / 工作流编排（图） | 要 checkpoint、人在回路、长任务、多 Agent | 官方强调 durable execution |
| **LlamaIndex** | 以数据/索引为中心的 LLM 应用 | 文档很多、检索质量优先 | Agent 能力有，但 RAG 更出名 |
| **OpenAI Agents SDK** | 轻量多 Agent：handoff、guardrails、tracing | 以 OpenAI 生态为主、想少抽象 | 也支持其他模型（provider-agnostic） |
| **AutoGen（Microsoft）** | 早期多 Agent 实验框架 | **历史参考** | 上游 README 标明 **已 archived**；新项目看 Microsoft Agent Framework |
| **Cursor / IDE Agent** | 产品内置编程 Agent | 写代码、改仓库、本地工具 | 学「工具循环与权限」很好；不是你要部署的 SDK |

另有索引型仓库如 `awesome-agent-quickstart`：多框架 helloworld，适合横向扫一眼。

## 怎么选（实用）

1. **先会手写 tool calling 循环**（见 05）——理解抽象在包什么。
2. 要生产级状态机、审批、恢复 → **LangGraph**。
3. 知识库问答为主 → **RAG（LangChain/LlamaIndex）**，Agent 可选。
4. 想少框架、官方 tracing → 试 **OpenAI Agents SDK**。
5. 中文系统课 → Datawhale `easy-langent`（开源精选已拉 README）。

## MCP（Model Context Protocol）一句话

把「工具/数据源」标准化成可插拔服务，Agent 通过 MCP Client 连 Server。面试说：像 USB，统一接入浏览器、文件系统、内部 API。只连**信任的** MCP；否则等于给远程执行权。
