## 先分清四个词

| 概念 | 一句话 | 典型例子 |
|---|---|---|
| **LLM 应用** | 调大模型生成文本，流程基本固定 | 翻译、摘要、写邮件草稿 |
| **RAG** | 先检索私有文档，再让模型基于检索结果回答 | 公司知识库问答 |
| **工作流编排 Workflow** | 你事先画好步骤（图/链），模型按节点执行 | LangGraph 固定审批流 |
| **Agent** | 模型**自主决定**下一步：调哪个工具、是否继续 | 查库→写代码→跑测试→改 bug |

口语记忆：Chatbot 主要「说」；Agent 会「做事」（调 API / 查库 / 跑命令），但仍需人类边界。

**不要夸大**：Agent 会幻觉、会乱调工具、会陷入循环；生产要用权限、审批、评测、可观测性。

## 安全红线（必读）

- **不要**让 Agent 擅自发邮件、转账、删库、改生产配置。
- **不要**把 API Key / 密码写进提示词或仓库；用环境变量 / vault。
- 危险操作必须 **Human-in-the-loop（人在回路）** 二次确认。
- 工具最小权限；输出要校验（schema / allowlist）。
