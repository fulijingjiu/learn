# Java 学习笔记

## 本目录

| 文件 | 内容 |
|---|---|
| `01-基础与开发知识.md` | JVM/JDK、集合、并发入门、异常、构建 |
| `02-常用框架.md` | Spring Boot / MVC / MyBatis / JPA 选型 |
| `03-实战技巧.md` | 分层、事务边界、接口设计、配置 |
| `04-Debug技巧.md` | 断点、日志、复现、NPE/并发/依赖冲突 |
| `05-代码片段与模式.md` | 连接池、事务、DTO、异常处理示例 |

## 建议顺序

基础 → 框架口述 → 代码片段敲一遍 → Debug 对着常见异常练 → 实战技巧回看项目。
