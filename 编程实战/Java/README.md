# Java 学习笔记

偏后端业务开发（Spring Boot）。面试口述 + 落地够用。

## 本目录

| 文件 | 内容 |
|---|---|
| `01-基础与开发知识.md` | JVM/JDK、集合、并发入门、异常、构建 |
| `02-常用框架.md` | Spring Boot / MVC / MyBatis / JPA 选型 |
| `03-实战技巧.md` | 分层、事务边界、接口设计、配置 |
| `04-Debug技巧.md` | 断点、日志、复现、NPE/并发/依赖冲突 |
| `05-代码片段与模式.md` | 连接池、事务、DTO、异常处理示例 |
| [06-MyBatis缓存与占位符.md](06-MyBatis缓存与占位符.md) | SqlSession 一/二级缓存、Spring 事务、跨 Mapper 失效与 SQL 注入边界 |

## 建议顺序

基础 → 框架口述 → 代码片段敲一遍 → Debug 对着常见异常练 → 实战技巧回看项目。

数据库细节见：`/workspace/面试八股/`。

## 补强专题怎么练

先看 06 的概念/对比表，再按“常见坑”设计成功、失败、回滚和并发测试；口述时说明生命周期和一致性边界，而不只背 API。开源对照与官方核验链接在文末，示例是学习骨架，未宣称实测。
