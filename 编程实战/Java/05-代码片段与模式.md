## 1. 统一返回 + 业务异常

```java
public record ApiResp<T>(int code, String message, T data) {
  public static <T> ApiResp<T> ok(T data) { return new ApiResp<>(0, "ok", data); }
  public static ApiResp<Void> fail(int code, String msg) { return new ApiResp<>(code, msg, null); }
}

public class BizException extends RuntimeException {
  private final int code;
  public BizException(int code, String msg) { super(msg); this.code = code; }
  public int getCode() { return code; }
}

@RestControllerAdvice
public class GlobalHandler {
  @ExceptionHandler(BizException.class)
  public ApiResp<Void> handleBiz(BizException e) {
    return ApiResp.fail(e.getCode(), e.getMessage());
  }
  @ExceptionHandler(Exception.class)
  public ApiResp<Void> handleOther(Exception e) {
    // 日志打栈
    return ApiResp.fail(500, "internal error");
  }
}
```

## 6. 简单缓存旁路（伪代码）

```java
public User getUser(long id) {
  User cached = redis.get("u:" + id);
  if (cached != null) return cached;
  User db = userMapper.find(id);
  if (db != null) redis.setex("u:" + id, 300, db);
  return db;
}
```
