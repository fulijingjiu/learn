# Java：基础与开发知识

## 口述一张图

源码 `.java` → 编译 `javac` → 字节码 `.class` → **JVM** 解释/JIT 执行。  
**JDK** = 开发工具（含编译器）+ JRE；**JRE** = 运行时（JVM + 标准库）。面试说「写代码要 JDK，只跑 jar 有时只要 JRE/定制运行时」。

## 必会清单

- **类型**：基本类型 vs 包装类型； enting 缓存 -128~127；判等用 `equals`，引用比 `==`
- **String**：不可变；`StringBuilder` 拼接；常量池直觉即可
- **集合**：`List`/`Set`/`Map`；`ArrayList` vs `LinkedList`；`HashMap` 拉链+红黑树直觉；线程安全用 `ConcurrentHashMap`，别无 `Hashtable`
- **异常**：`Checked` vs `Unchecked`；业务异常不要吞；终于块/ try-with-resources 关资源
- **并发入门**：线程 vs 进程；`synchronized` / `volatile` 区别一句话；线程池不要 `Executors` 无界队列（阿里规约）
- **构建**：Maven/Gradle；`pom` 坐标、依赖冲突靠树（`mvn dependency:tree`）

## 开发日常知识

- 包名、模块边界清晰；对外 API 稳定，内部可改
- 日志用 SLF4J，别 `System.out`
- 配置外置：`application.yml` + 环境变量；密钥不进仓库
- 时间用 `Instant`/`OffsetDateTime`，慎用可变 `Date`
- 空值：Optional 别滥用；接口层校验（Bean Validation）

## 面试高频口述

1. **HashMap 为什么线程不安全？** 并发扩容/链表可能丢数据；用 CHM。
2. **== 和 equals？** == 比引用（基本类型比值）；equals 比内容（需正确重写）。
3. **GC 知道哪些？** 新生代/老年代、Minor/Major；常见收集器名字即可，深挖看岗位。
