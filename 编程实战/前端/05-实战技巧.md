# 前端实战技巧

## 工程化

- 脚手架：Vite + React + TS；全栈可选 Next.js（见开源 `nextjs-README.md`）。  
- 规范：ESLint + Prettier + husky + lint-staged。  
- 路径别名：`@/` → `src/`。  
- 环境：`.env.development` / `.env.production`；`VITE_` / `NEXT_PUBLIC_` 前缀才进前端包。

## 目录习惯

```
src/
  app/ or pages/     # 路由
  components/ui/     # 纯 UI
  features/<域>/     # 业务（api、hooks、components）
  hooks/ lib/ types/
```

按**业务域**拆，比按文件类型硬拆更好维护。

## 接口层

- 集中 `apiClient`（axios / fetch 封装）：baseURL、超时、token、错误码。  
- 401 → 跳登录；业务错 → toast；网络错 → 可重试。  
- 服务端状态用 React Query：`queryKey` 规范、`invalidateQueries` 写后刷新。

## 表单与表格

- 简单：组件库 Form。  
- 复杂：React Hook Form + zod。  
- 表格：服务端分页；筛选条件进 URL query，可分享可回退。

## 权限

- 路由守卫 + 按钮级权限（指令/组件 `Can`）。  
- 权限码来自后端；前端隐藏不等于安全，接口仍要鉴权。

## 性能与体验

- 路由懒加载；首屏骨架屏。  
- 防抖搜索；大上传分片。  
- 错误边界 + 监控（Sentry 一类）。

## 发布

- 静态资源 CDN；HTML 短缓存，hashed 资源长缓存。  
- 版本号 / tag；回滚预案。  
- Preview 环境对齐生产配置。

## 和 AI 协作（干活）

- 贴：**报错全文 + 相关文件 + 期望行为**。  
- 让 AI 写 story / 单测边界，你负责对一下真实设计稿。  
- 生成的 antd/MUI 代码要过一遍：是否多余重渲染、是否无障碍。
