# learn-kit · 学习资料包

自学用笔记与开源精选摘录，整理后归档到本仓库。

仓库地址：https://github.com/fulijingjiu/learn

## 目录

| 目录 | 内容 |
|---|---|
| [`面试八股/`](./面试八股/) | MySQL / PostgreSQL / SQL Server 八股、数据库实战、开源精选 |
| [`编程实战/`](./编程实战/) | Java、Python、前端（React/Node/Storybook）、运维部署、AI Agent |

各子目录有自己的 `README.md`，建议从那里开始。

## 怎么用

1. 先读子目录 README，按建议顺序刷。  
2. `开源精选/` 是 GitHub 公开仓库择优摘录，文首有来源与许可证；**不替代**本地笔记。  
3. 有明确开源许可的可按原许可使用；未声明许可证的仅供个人学习，勿再分发。
