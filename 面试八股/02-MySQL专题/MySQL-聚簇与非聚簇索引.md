# 聚簇索引 vs 非聚簇索引

> 学习笔记 · 面试八股

## 聚簇索引（InnoDB 主键）

- 数据和索引在**同一棵** B+ 树上。
- 叶子节点存的是**整行数据**。
- 按主键查：找到叶子就拿到行。
- 一张表通常只有一棵聚簇索引。

## 非聚簇索引（二级索引）

- 叶子存的是「索引列 + **主键值**」，不是整行。
- 查二级索引后，往往还要用主键再去聚簇树里找一次 → **回表**。

## 怎么记

- 聚簇 = 叶子就是数据。
- 非聚簇 = 叶子是「门牌号（主键）」，还要再进一次数据门。

## 面试口述版

「InnoDB 主键是聚簇索引，叶子存整行；普通索引是二级索引，叶子存主键，查完常要回表。」
