# 最左前缀原则

> 学习笔记 · 面试八股

## 含义

联合索引 `(a, b, c)` 像按 a → b → c 排序的电话簿。查询必须从**最左边的列**开始用，不能跳过。

## 能用上 / 用不上

| 条件 | 能否较好用到索引 |
|---|---|
| `a` | 能 |
| `a, b` | 能 |
| `a, b, c` | 能 |
| 只有 `b` / 只有 `c` / `b, c` | 用不上或很差（跳过了 a） |
| `a, c` | 通常只用到 `a`，`c` 用不上（中间断了） |

## 为什么

B+ 树先按第一列排。没有左边的列，就不知道从哪一段开始找。

## 面试口述版

「联合索引遵循最左前缀：必须从最左列开始连续匹配；跳列或从中间开始，索引用不上或只能用一部分。」
